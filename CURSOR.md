# Reglas de trabajo del proyecto

La habilidad disponible es [Karpathy Guidelines](skills/karpathy-guidelines/SKILL.md). Leerla antes de escribir, revisar o refactorizar código.

- Explicitar supuestos relevantes y criterios de comprobación.
- Implementar solo lo solicitado, con la solución más sencilla suficiente.
- Limitar los cambios al objetivo; no refactorizar código ajeno a la tarea.
- Verificar el resultado con las comprobaciones apropiadas.

Este repositorio no contiene una regla automática .cursor/rules ni CLAUDE.md. No se presupone que el editor cargue esta habilidad automáticamente.

La fuente funcional aprobada es el [Spec Kit Unificado](SpecKit_Firma_Legal_Unificado_v2.docx). Ver [README.md](README.md) para sincronizar documentos, contrato y pruebas.
